# מעוף | אתר מכירתי לצילום אווירי ברחפן

אתר נחיתה סטטי, נקי ומודרני, בעברית (RTL), לשירותי צילום רחפן.
ללא תלויות וללא שלב בנייה: HTML, CSS ו-JavaScript בלבד.

## הרצה מקומית

פותחים את `index.html` בדפדפן, או מריצים שרת סטטי:

```bash
python3 -m http.server 8080
# ואז נכנסים ל-http://localhost:8080
```

## מבנה

```
index.html      – כל הסקשנים של העמוד
css/style.css   – עיצוב, אנימציות ורספונסיביות
js/main.js      – תפריט מובייל, אנימציות גלילה, מונים, טופס
```

## סקשנים בעמוד

1. Hero עם רחפן מונפש, עננים נעים וקריאה לפעולה
2. פס לקוחות
3. שירותים (6 תחומים)
4. תיק עבודות
5. איך זה עובד (4 שלבים)
6. למה אנחנו + מונים מונפשים
7. חבילות ומחירים
8. המלצות לקוחות
9. שאלות נפוצות
10. טופס הצעת מחיר + פרטי קשר
11. פוטר וכפתור וואטסאפ צף

## מה כדאי להחליף לפני עלייה לאוויר

- **תמונות תיק העבודות**: כרגע איורי SVG מופשטים כממלאי מקום. החליפו כל `<svg>` בתוך `figure.shot` בתגית `<img>` עם צילום אמיתי.
- **טלפון ואימייל**: חפשו `972501234567` ו-`hello@maof.co.il` ב-`index.html` וב-`js/main.js`.
- **שם המותג**: "מעוף" מופיע בלוגו, בכותרת ובפוטר.
- **מחירים וחבילות**: בסקשן `#packages`.
- **שליחת הטופס**: כרגע הטופס פותח וואטסאפ עם הפרטים. לחיבור לשירות טפסים (Formspree, Netlify Forms, EmailJS) ערכו את הבלוק המסומן ב-`js/main.js`.
