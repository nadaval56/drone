# סולארסקאן | אתר מכירתי לבדיקות תרמיות של מערכות סולאריות ברחפן

אתר נחיתה סטטי, נקי ומודרני, בעברית (RTL), לשירות בדיקה תרמית של מערכות
פוטו-וולטאיות ברחפן (DJI Matrice 30T). ללא תלויות וללא שלב בנייה: HTML, CSS ו-JavaScript בלבד.

## הרצה מקומית

```bash
python3 -m http.server 8080
# ואז נכנסים ל-http://localhost:8080
```

## מבנה

```
index.html       – דף הבית
report.html      – דוח בדיקה לדוגמה (וגם תבנית לדוחות אמיתיים)
css/style.css    – עיצוב דף הבית
css/report.css   – עיצוב הדוח, כולל הדפסה ל-PDF
js/main.js       – תפריט, אנימציות, מחשבון הפסד, טופס
js/report.js     – נתוני הדוח + רינדור אוטומטי של מפה, טבלאות וכרטיסים
```

## דף הבית

1. Hero עם הדמיית סריקה תרמית של מערך פאנלים
2. ארבע התקלות הנפוצות (תא חם, דיודה מעקפית, סטרינג מנותק, PID)
3. מחשבון הפסד שנתי לפי גודל מערכת, תעריף ואחוז הספק אבוד
4. השירות ומתי עושים בדיקה
5. תצוגה מקדימה של הדוח עם קישור לדוח לדוגמה
6. ציוד ומתודולוגיה (Matrice 30T, תנאי IEC TS 62446-3)
7. איך זה עובד, מחירים לפי גודל מערכת, מבצע היכרות
8. שאלות נפוצות, טופס הצעת מחיר, וואטסאפ

## הפקת דוח אמיתי

כל נתוני הדוח נמצאים באובייקט `REPORT` בראש `js/report.js`:
פרטי לקוח ואתר, תנאי הבדיקה, מבנה המערכת (מהפכים, סטרינגים, פאנלים לסטרינג)
ורשימת ממצאים. הדף מייצר לבד את המדדים, המפה, הטבלאות, הכרטיסים וההמלצות.
מחליפים את הנתונים, פותחים בדפדפן ולוחצים "הדפסה / שמירה כ-PDF".

בגרסה זו התמונות התרמיות והחזותיות בכרטיסי הממצאים הן איורי SVG.
בדוח אמיתי מחליפים אותן בתמונות מהרחפן (בפונקציות `thermalSvg` ו-`visualSvg`
או ישירות בכרטיסים).

## הנחות המחשבון

ב-`js/main.js`: תפוקה של 1,650 קוט"ש לקילוואט בשנה (ערך אופייני בישראל)
ופאנל ממוצע של 0.55 קילוואט. ניתן לשנות בראש הקובץ.

- **טלפון ואימייל**: חפשו `972501234567` ו-`hello@solarscan.co.il` ב-`index.html` וב-`js/main.js`.
